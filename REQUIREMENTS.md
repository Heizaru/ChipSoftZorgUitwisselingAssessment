# REQUIREMENTS.md
Dit is de originele assessment opdracht zoals ik die van ChipSoft heb ontvangen. 

## Business case
Een patiënt wordt ontslagen uit Ziekenhuis A en doorverwezen naar verpleeghuis B. Bij deze
verwijzing wordt er een verwijsbrief en informatie over de allergieën van de patiënt verstuurd
naar verpleeghuis B. Bij aankomst in verpleeghuis B vraagt het verpleeghuis om extra
informatie over het medicatiegebruik van de patiënt.
De opdracht is om een ASP.NET Core REST API (C#) te bouwen die het mogelijk maakt voor
Ziekenhuis A en verpleeghuis B om gegevens uit te wisselen.

## Requirements
- Gebruik .NET 10.0 -> https://dotnet.microsoft.com/download
- Maak het mogelijk om documenten uit te wisselen via een REST API
- Er dienen validatie checks uitgevoerd te worden
- Er dient foutafhandeling te zijn
- Er dient gelogged te worden dat er informatie uitgewisseld is tussen partijen en wat er
  uitgewisseld is
- De source code dient leesbaar en onderhoudbaar te zijn
- Er dient documentatie beschikbaar gesteld te worden waarin de ontwerpkeuzes uitgelegd
  worden en een beschrijving hoe de software werkt
  Optioneel:
- Er mag gebruik gemaakt worden van een database, in-memory data opslaan is ook
  prima.
